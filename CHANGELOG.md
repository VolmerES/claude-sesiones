## [cses 0.1.0] - unreleased

First version of `cses`, a fork of ccresume 2.0.0 under a new name. Everything below this
entry is ccresume's history. / Primera versión de `cses`, un fork de ccresume 2.0.0 con
nombre propio. Lo que hay debajo es el historial de ccresume.

### Added
- Three-column layout: folder tree | conversations | preview, with `←` `→` between them
- Folder tree with conversation counts that can expand any folder on disk
- Type-to-search in the focused column, ignoring case and accents
- Favorite conversations and folders (`Ctrl+E`), stored in `~/.cses/favoritos.json`
- Mouse support: click, double-click and wheel
- `esc` history to go back to where you were
- Incremental index in `~/.cses/indice.json`: only new lines are read
- Conversation titles generated by Claude Code (or set with `/rename`)
- Several accounts (`~/.claude-*`): `Ctrl+A`, per-folder rules, `cses accounts`,
  `cses new-account`, `cses login`
- Open in a new Windows Terminal or tmux tab (`Ctrl+T`), forks (`Ctrl+F`)
- `●` for conversations open in another terminal, and a prompt before reopening them
- `cses list` for use without the UI
- Accounts panel next to `claude` (Windows Terminal or tmux): click another account and
  the same conversation reopens with it, without logging in again; marks accounts that
  hit a usage limit and when they come back; "+ Add account"
- English and Spanish UI

### Changed
- On Windows `claude.exe` is launched directly: no startup pause or "press ENTER"
- Full-screen UI in the terminal's alternate screen
- Symbols such as `★ ● ▸` are measured as one column wide (only emoji-presentation
  characters take two)

### Removed
- Pagination, the option editor and TOML key bindings

## [2.0.0] - 2026-05-08

### Added
- GitHub Actions based npm publishing via trusted publishing (OIDC)
- npm provenance-ready release workflow triggered by GitHub Releases
- Regression tests for non-directory and broken symlink entries in Claude project scanning

### Changed
- Raised the supported Node.js runtime to 22 / 24 LTS
- Moved local tooling and CI workflows onto the mise-based workflow
- Switched dependency update policy to monthly Dependabot review windows
- Updated the release process documentation for automated npm publishing
- Refreshed stable dependency and GitHub Action versions across the project

### Fixed
- Skip plain files and broken symlinks when scanning `~/.claude/projects` for conversations

## [1.0.0] - 2025-08-06

### Added
- Display git branch in conversation preview for newer Claude Code versions (#46)
- New session feature - press `n` to start a new Claude session in selected project directory (#48)
- Interactive command editor - press `-` to edit Claude CLI options before starting/resuming sessions (#49)
- Full conversation view (experimental) - press `f` to toggle full message view (#50)

### Changed
- Major version bump to indicate project maturity and feature completeness
- Improved type safety and test coverage throughout the codebase (#51)

## [0.3.0] - 2025-07-11

### Added
- New `--hide` option to hide specific message types (#27)
  - Hide tool use messages with `--hide tool`
  - Hide thinking messages with `--hide thinking`
  - Hide user messages with `--hide user`
  - Hide assistant messages with `--hide assistant`
  - Default behavior (no arguments): `--hide` hides both tool and thinking messages
  - Multiple message types can be hidden: `--hide tool thinking user`
- Improved command-line argument parsing with validation for hide options
